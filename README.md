# 🎵 새찬송가 앱 (645곡) — 사용 및 배포 안내

폴더 하나째로 동작하는 웹앱(PWA)입니다. 인터넷이 연결된 적이 있으면 이후에는 **오프라인에서도 완전 작동**합니다.

## 📁 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (화면 + 기능) |
| `hymns.json` | 찬송가 데이터 645곡 (num / title / lyrics) |
| `manifest.webmanifest` | 앱 정보 (이름, 아이콘, 색상) |
| `sw.js` | 오프라인 캐싱 (서비스 워커) |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 앱 아이콘 |

## 🚀 폰에 설치해서 쓰기 (권장)

1. **폴더 전체를 웹에 올립니다** — GitHub Pages(무료), Netlify(무료), 교회 서버 등 어디든
   - GitHub Pages 예시: 저장소 만들기 → 파일 업로드 → Settings → Pages → Branch: main 저장 → `https://계정명.github.io/저장소명/` 접속
2. 폰 브라우저(Chrome/Safari)로 그 주소에 접속
3. 설치:
   - **Android (Chrome)**: 주소창 우측 ⋮ 메뉴 → **앱 설치** (또는 홈 화면에 추가)
   - **iPhone (Safari)**: 하단 공유 버튼 → **홈 화면에 추가**
4. 홈 화면 아이콘으로 앱처럼 실행, 인터넷 없이도 사용 가능

> 참고: PC에서 폴더를 더블클릭해 열면(file://) 기본 기능은 동작하지만, **앱 설치·오프라인 기능은 http/https에서만** 작동합니다.

## ✏️ 나중에 가사를 수정하려면

1. `hymns.json`에서 해당 곡의 `lyrics` 수정 (또는 `가사교체/convert_lyrics.py` 사용)
2. `sw.js` 상단의 `CACHE = 'hymnal-v1'` → `'hymnal-v2'`로 버전 업 (기존 사용자 캐시 갱신)
3. 파일 다시 업로드

## 💾 기기 변경 시 (데이터 이전)

앱 내 **⚙️ 설정 → 💾 백업**에서 텍스트를 복사/파일 저장 → 새 기기 앱에서 **↩️ 복원**에 붙여넣기
(즐겨찾기, 예배 순서, 최근 본 곡, 글자 크기, 다크모드 설정이 함께 이동됩니다)

## 🧩 주요 기능

- 🔍 검색: 장 번호 / 제목 / 가사 일부 / **초성(ㅅㅈ)**, 검색어 하이라이트, 번호 입력 후 엔터로 바로 열기
- 📂 분류별: 새찬송가 공식 분류 15개 대분류 + 소분류(성탄·고난·부활 등)
- ⭐ 즐겨찾기 / 🕘 최근 본 곡
- 📋 예배 순서: 곡 묶음 저장·순서 변경·"이 순서로 보기"(다음 곡 바로가기)
- 📽️ 프로젡터 모드: 한 절씩 큰 글씨(좌: 이전 / 우: 다음) + 화면 꺼짐 방지
- 📋 가사 복사 / 🔗 공유 / 가± 글자 크기 / 🌙 다크모드
- ⬅️ 스마트폰 뒤로가기 버튼: 이전 화면 복귀 → 홈 → 앱 종료
