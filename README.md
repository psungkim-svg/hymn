# 🎵 SK-hymn (새찬송가 645곡)

**앱 주소 → https://psungkim-svg.github.io/hymn/**

폴더 하나로 동작하는 웹앱(PWA)입니다. 한 번 접속한 뒤에는 **인터넷 없이도 완전 동작**합니다.

## 📁 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (화면 + 기능) |
| `hymns.json` | 찬송가 645곡 (num / title / lyrics) |
| `categories.json` | 주제 분류 (themes / tags) — 곡당 태그 **1개 사용** |
| `ccm.json`, `en.json` | CCM / 영어 찬송 (내 모드에서만 표시) |
| `manifest.webmanifest` | 앱 정보 (이름 `SK-hymn` · 아이콘 · 색상) — **확장자 `.txt` 붙으면 설치가 깨짐** |
| `sw.js` | 오프라인 캐싱 (서비스 워커) |
| `version.json` | 새 버전 알림용 버전 정보 |
| `icon-192.png`, `icon-512.png` | 일반 앱 아이콘 (“찬송” 글자 확대) |
| `icon-maskable-512.png` | 마스커블 아이콘 (원형/사각 마스크용, 배경 전체 노란색) |
| `apple-touch-icon.png` | iPhone 홈 화면 아이콘 |

> 아이콘 3종은 같은 구도이며, “찬송” 글자를 Small 아이콘에서도 읽히도록 크게 늘렸습니다.  
> `icon-maskable-512.png`만 배경을 캔버스 전체로 채운 버전입니다.

> ℹ️ **내 모드 안내**: 정적 웹앱이라 `ccm.json` / `en.json` 자체는 공개 URL에 있고, 기기에서 `hymn_owner` 값을 바꾸면 탭을 켤 수 있습니다. 내 모드는 **화면 분리용**이며 접근 통제용 보안 기능은 아닙니다.

## 📱 폰에 설치하기

1. 폰 브라우저로 https://psungkim-svg.github.io/hymn/ 접속
2. **Android(Chrome)**: ⋮ 메뉴 → 앱 설치 / **iPhone(Safari)**: 공유 → 홈 화면에 추가
3. 홈 화면 아이콘으로 실행, 인터넷 없이 사용 가능

## 🧩 주요 기능

- 🔢 번호 키패드 / 🔍 번호·제목·가사·초성 검색
- 📂 40개 주제 분류, 곡당 태그 1개 정책
- ✏️ 가사 고치기 — 연필 버튼 굵기는 유지, 길이만 짧게 정리 / 편집창 가사 입력 공간 확대
- 📋 예배 순서 저장·정렬·자동 연결
- 📽️ 프로젝터 모드 — 절 단위 넘김, 화면 꺼짐 방지
- ⭐ 즐겨찾기, 🔤 글자 크기(17~48px), 📽️ 프로젝터 크기(60~220%), 🌙 다크모드
- 💾 백업·복원 (검증된 데이터만 복원)

## 🔄 업데이트 방법

1. 바뀐 파일을 저장소에 업로드
2. **`sw.js` 상단 `CACHE = 'hymnal-v9-10'` 버전을 올리기** (예: `hymnal-v9-11`)
3. `index.html`의 `APP_VERSION`, `version.json`의 `version`도 같은 값으로 올리기
4. 1~2분 뒤 Pages 반영 → 앱을 한 번 열면 자동 갱신

> 안 바뀌는 폰이 있으면 ⚙️ 설정 맨 아래 버전 글씨를 7번 연속 탭 → 캐시를 비우고 최신 파일을 다시 받습니다.
