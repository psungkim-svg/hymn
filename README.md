# 🎵 SK새찬송가 앱 (645곡)

**앱 주소 → https://psungkim-svg.github.io/hymn/**

폴더 하나로 동작하는 웹앱(PWA)입니다. 한 번 접속한 뒤에는 **인터넷 없이도 완전 동작**합니다.

## 📁 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (화면 + 기능) |
| `hymns.json` | 찬송가 645곡 (num / title / lyrics) |
| `manifest.webmanifest` | 앱 정보 (이름·아이콘·색상) — **확장자 `.txt` 붙으면 설치가 깨짐** |
| `sw.js` | 오프라인 캐싱 (서비스 워커) |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | 앱 아이콘 |

## 📱 폰에 설치하기

1. 폰 브라우저로 https://psungkim-svg.github.io/hymn/ 접속
2. **Android(Chrome)**: ⋮ 메뉴 → 앱 설치 / **iPhone(Safari)**: 공유 → 홈 화면에 추가
3. 홈 화면 아이콘으로 실행, 인터넷 없이 사용 가능

## 🧩 주요 기능

- 🔢 **번호 키패드** — 예배 중 숫자 빠르게 입력, 제목 실시간 확인 후 자동 열기
- 🔍 **검색** — 번호 / 제목 / 가사 / 초성(ㅅㅈ), **가사로 걸리면 해당 가사 줄을 미리보기**로 표시 + 하이라이트
- 📂 **분류별** — 공식 15개 대분류 + 소분류, 원하는 곡을 분류에 직접 추가 가능
- ✏️ **내 분류** — 나만의 분류 만들기
- 📋 **예배 순서** — 곡 묶음 저장·순서 변경·"이 순서로 보기"
- 📽️ **프로젝터 모드** — 한 절씩 큰 글씨, 화면 꺼짐 방지, **마지막 절에서 넘기면 예배 순서상 다음 곡으로 자동 연결**
- ⭐ **즐겨찾기** — `내 순서 / 번호순` 전환, ☰ 잡고 드래그로 정렬
- 🔤 **글자 크기** — 슬라이더(16~40px) + **프로젝터 전용 크기(60~180%) 별도 저장**
- 📋 복사 / 🔗 공유 / 🌙 다크모드 / ⬅️ 폰 뒤로가기 연동
- 💾 백업·복원 — 기기 바꿀 때 즐겨찾기·예배순서·분류 이전

## 🔄 업데이트 방법 (가사 수정·기능 추가 후)

1. 바뀐 파일을 저장소에 업로드
2. **`sw.js` 상단 `CACHE = 'hymnal-v5-1'` 의 버전을 반드시 올리기** (예: `hymnal-v5-2`)
3. 1~2분 뒤 Pages 반영 → 사용자는 앱을 한 번 열면 자동 갱신

> 안 바뀌는 폰이 있으면: **⚙️ 설정 맨 아래 버전 글씨를 7번 연속 탭** → 캐시를 비우고 최신 파일을 강제로 다시 받습니다.
